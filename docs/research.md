# Почему людям не нравятся Excel, Google Sheets и Notion

Разбор отзывов (G2, Capterra, App Store, форумы Microsoft) и исследований ошибок в таблицах.
Цель — понять, какие проблемы higtclass должен решить с первого дня.

> Оговорка: большинство отзывов — отдельные мнения, а не статистика. Общие оценки у всех трёх
> продуктов высокие (Excel 4.7–4.8, Sheets 4.7). Жалобы ниже — это повторяющиеся темы, а не
> «все ненавидят Excel».

## 1. Excel

| Проблема | Что пишут |
|---|---|
| **Нужно уметь** | Результат зависит от знаний пользователя; бухгалтер из малого бизнеса называет это главным недостатком; новых сотрудников трудно обучать. |
| **Ошибки в формулах** | Одна ошибка в формуле или ссылке на ячейку ломает весь лист. Аудиты реальных таблиц находят ошибки в 24% (старые методы) и до 94% (тщательные аудиты); 1–2.5% ячеек содержат исходные ошибки. |
| **Порча файлов и потеря данных** | Большие и сложные файлы портятся, без бэкапов данные теряются. |
| **Медленно на больших данных** | Тормозит и зависает. |
| **Телефон** | Файлы открываются только для чтения (неподдерживаемые функции), «редактирование запрещено», неудобный интерфейс для правок. |
| **Хаос версий** | Файлы пересылают почтой, копии `final_v2.xlsx` расходятся. Цифры опросов в сети ненадёжны, но сама проблема описана везде. |
| **Copilot (ИИ в Excel)** | Работает только если данные оформлены как «таблица», без объединённых ячеек, файл в OneDrive; может вставить формулу с неправильной колонкой, и результат выглядит правдоподобно. |

## 2. Google Sheets

| Проблема | Что пишут |
|---|---|
| **Тормозит задолго до лимита** | Лимит 10 млн ячеек, но замедление начинается на десятках–сотнях тысяч строк, особенно с формулами (QUERY, FILTER, ARRAYFORMULA, IMPORTRANGE). |
| **Форматирование** | Вставка ломает оформление; часть форматирования применяется автоматически и не настраивается. |
| **Телефон** | Данные вылезают за ячейки, ограниченный функционал. |
| **Офлайн** | Ограниченная работа без интернета. |
| **Слабее Excel в сложном** | Меньше продвинутых функций. |

## 3. Notion (базы данных)

| Проблема | Что пишут |
|---|---|
| **Сложно начать** | Гибкость перегружает; на сложные системы уходит много времени на настройку. |
| **Тормозит на больших базах** | Медленно грузит страницы с базами от ~1000 записей. |
| **Офлайн** | Можно смотреть только недавно открытые страницы. |
| **Телефон** | Медленнее и беднее десктопа, жалобы на зависания при редактировании. |
| **Цена ИИ** | Полный ИИ теперь входит только в бизнес-тариф (~$20 за пользователя в месяц). |
| **Язык** | Интерфейс на английском и ещё нескольких языках — для части людей это барьер. |

## 4. Почему люди бросают вести учёт (личные финансы, «Вася копит»)

- Каждая покупка превращается в ввод данных — трение, а не время, убивает привычку.
- Шаблоны с ручными расчётами бросают: каждый ручной шаг — точка отказа.
- Слишком гибкая система сама становится причиной бросить.
- «Пустой лист» пугает.

## Выводы → принципы higtclass

| # | Боль | Что делаем |
|---|---|---|
| 1 | Нужно учиться | Колонки с типами (деньги, дата, выбор, галочка), итоги считаются сами. Таблицу под задачу собирает ИИ или шаблон — пустого листа нет. |
| 2 | Ошибки в формулах | Формулы ссылаются на **имя колонки** (`[Цена] * [Кол-во]`), а не на ячейку `B7`, и считаются для всей колонки — нечего «протягивать» и некуда промахнуться. Типы проверяют ввод. |
| 3 | Ручной ввод утомляет | Форма «Записать» в одно касание, сегодняшняя дата по умолчанию, понимаем «5к», «1 500,50», «вчера». Голос и фото чека через ИИ. |
| 4 | Плохо на телефоне | Mobile-first: на телефоне строки показываются карточками, а не мелкой сеткой. |
| 5 | Тормозит | Данные хранятся локально на устройстве (мгновенно), отрисовка только видимых строк, пересчёт только изменённого. |
| 6 | Нет офлайна | Local-first: всё работает без интернета, синхронизация догоняет потом. |
| 7 | Хаос версий, порча файлов | Нет файлов. Каждое изменение — операция в журнале: история, отмена любого шага, одна версия на всех устройствах. |
| 8 | ИИ ошибается на «грязных» данных | У нас данные всегда структурированы, поэтому ИИ видит типы и имена колонок. Каждое действие ИИ показывается списком и отменяется одной кнопкой. |
| 9 | Форматирование ломается | Формат задаёт тип колонки (валюта, дата в формате страны), а не ручная раскраска; вставка разбирает значения по типу. |
| 10 | Язык | 5 языков с первого дня: русский, украинский, английский, немецкий, испанский. |
