# Архитектура higtclass

Один код интерфейса — для сайта и для `.exe` (Tauri). Сервер — свой (позже Hetzner), ИИ — Claude API.

```
higtclass/
├── packages/core   — «мозг»: типы, разбор ввода на 5 языках, формулы, операции, итоги, шаблоны.
│                     Чистый TypeScript без зависимостей: работает в браузере, в .exe и на сервере.
├── apps/web        — React-интерфейс (Vite). Его же собирает Tauri в .exe.
├── apps/desktop    — Tauri-обёртка для Windows (позже).
└── apps/api        — сервер: ИИ-помощник (Claude), аккаунты, синхронизация, Postgres (позже).
```

## Модель данных

- **Workspace** → **Table** → **Column** (тип: `text`, `number`, `money`, `date`, `select`,
  `checkbox`, `formula`) и **Row** (значения по id колонки).
- Даты хранятся как `YYYY-MM-DD`, деньги — числом; валюта и формат — это отображение.
- Формулы ссылаются на колонки по имени: `[Цена] * [Кол-во]`. При переименовании колонки
  формулы переписываются автоматически.

## Операции (главная механика)

Любое изменение — это **операция** (`Op`): `table.create`, `rows.insert`, `cells.set`, ...

- `applyOp(workspace, op)` — чистая функция, одинаковая на клиенте и сервере.
- `invertOp(workspace, op)` — обратная операция → отмена любого шага.
- Журнал операций — основа истории, синхронизации между устройствами и действий ИИ:
  ИИ не трогает данные напрямую, он возвращает список операций, клиент их показывает и применяет,
  пользователь может отменить.

Команды (`commands.ts`) — удобный слой поверх операций: «добавить запись из сырого ввода»,
«создать таблицу из шаблона». Они разбирают ввод и выдают готовые операции.

## Языки

`ru`, `uk`, `en`, `de`, `es`. Разбор чисел (запятая/точка, «5к», «5 mil»), относительных дат
(«вчера», «вчора», «gestern», «ayer»), да/нет — по языку пользователя. Интерфейс — словари.

## Этапы

1. ✅ `core`: модель, разбор ввода, формулы, операции, отмена, итоги, шаблоны + тесты.
2. ✅ `web`: умные таблицы, карточки на телефоне, форма «Записать», шаблоны, 5 языков, локальное хранение.
3. ИИ-сервер: текст, голос, фото чека → операции.
4. Аккаунты, Postgres, синхронизация, офлайн-очередь.
5. Tauri `.exe` + сборка в GitHub Actions.
6. Режим сетки A1 для продвинутых.
