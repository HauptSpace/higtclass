# Архитектура Sumira

Один код интерфейса — для сайта и для `.exe` (Tauri). Сервер — свой (позже Hetzner), ИИ — Claude API.

```
higtclass/
├── packages/core   — «мозг»: типы, разбор ввода на 5 языках, формулы, операции, итоги, шаблоны.
│                     Чистый TypeScript без зависимостей: работает в браузере, в .exe и на сервере.
├── apps/web        — React-интерфейс (Vite). Его же собирает Tauri в .exe.
├── apps/desktop    — Tauri-обёртка для Windows (позже).
└── apps/api        — сервер: ИИ-помощник (Claude), аккаунты, синхронизация, Postgres (позже).
```

## Модель данных

- **Workspace** → **Table** → **Column** (тип: `text`, `number`, `money`, `date`, `select`,
  `checkbox`, `formula`) и **Row** (значения по id колонки).
- Даты хранятся как `YYYY-MM-DD`, деньги — числом; валюта и формат — это отображение.
- Формулы ссылаются на колонки по имени: `[Цена] * [Кол-во]`. При переименовании колонки
  формулы переписываются автоматически.

## Операции (главная механика)

Любое изменение — это **операция** (`Op`): `table.create`, `rows.insert`, `cells.set`, ...

- `applyOp(workspace, op)` — чистая функция, одинаковая на клиенте и сервере.
- `invertOp(workspace, op)` — обратная операция → отмена любого шага.
- Журнал операций — основа истории, синхронизации между устройствами и действий ИИ:
  ИИ не трогает данные напрямую, он возвращает список операций, клиент их показывает и применяет,
  пользователь может отменить.

Команды (`commands.ts`) — удобный слой поверх операций: «добавить запись из сырого ввода»,
«создать таблицу из шаблона». Они разбирают ввод и выдают готовые операции.

## Языки

`ru`, `uk`, `en`, `de`, `es`. Разбор чисел (запятая/точка, «5к», «5 mil»), относительных дат
(«вчера», «вчора», «gestern», «ayer»), да/нет — по языку пользователя. Интерфейс — словари.

## Связи, импорт, отчёты

- **Связь** (`link`): ячейка хранит id строки другой таблицы, показывает её имя (первая текстовая
  колонка). Имя можно написать или надиктовать — команды найдут строку. **Из связи** (`lookup`)
  показывает любую колонку связанной строки и работает в формулах.
- **Импорт** (`infer.ts`): по значениям колонки угадывается тип — даты, деньги (по заголовку или
  знаку валюты), выбор (мало повторяющихся значений), галочки. Перед загрузкой типы можно поправить.
- **Отчёт** — сохранённый вопрос к таблице: что считать (сумма, среднее, количество), как разбить
  (по колонке, по связи, по месяцам), каким графиком показать. Хранится операциями, отменяется.

## «Для вас»: сроки и подсказки

Профиль (страна, кто вы, налоговая ситуация) → набор правил (`knowledge.ts`): сроки (декларации,
платежи, НДС), государственные праздники Германии (банки закрыты) и подсказки с действием в одну
кнопку (добавить таблицу, колонку налога, следить за лимитом дохода). Правила — это данные:
сервер отдаёт свежий набор по `/api/rules` (файл `SUMIRA_RULES_FILE`), приложение обновляется без
релиза, а без интернета работает встроенный набор. Каждое правило ссылается на источник.

## Деньги, цели, фильтры (после теста на 5 персонах)

- **Учёт** (`ledger.ts`): у таблицы есть смысл денег — доходы, расходы или и то и другое (по колонке
  «Тип» или по знаку), плюс «считать только оплаченное». Сверху вместо суммы всего подряд — доход,
  потрачено и остаток (прибыль). Лимиты и налоги на «Для вас» берут доход из всех таких таблиц.
- **Итог по связям** (`rollup`): сумма/количество записей другой таблицы, которые ссылаются на эту
  строку. Так «Остаток = Поступило − Продано» и «Выручка клиента» считаются сами.
- **Цель** у таблицы: сколько накоплено, сколько осталось и сколько откладывать в месяц.
- **Периоды и фильтры** (`periods.ts`, `aggregate.ts`): неделя, месяц, квартал, год, следующая неделя,
  свои даты; фильтры по любой колонке; сохранённые виды. Итоги, отчёты и выгрузка считают только то,
  что видно.
- **Быстрая запись без ИИ** (`quick.ts`): «кава 85», «вчора таксі 240», «Олег 12000» разбираются
  прямо в приложении — бесплатно и без интернета. ИИ нужен только для сложного.
- **Сетка как в Excel**: стрелки, выделение, копирование/вставка блоков, заполнение вниз, Escape
  отменяет; длинные таблицы рисуют только видимые строки. Ещё доска по статусам и календарь.

## Аккаунты, облако, команда

- Вход по почте и паролю (пароль хранится как scrypt-хеш, сессия — случайный токен, в базе только его
  хеш). Неудачные входы ограничены: 10 попыток за 10 минут.
- Пространство (workspace) живёт на сервере в SQLite (`SUMIRA_DB`), у него номер версии и журнал
  операций. Устройство отправляет свои операции, сервер применяет их тем же `applyOp` и нумерует;
  другие устройства забирают то, что пропустили. Если операция больше не применима (строку уже удалили
  на другом устройстве) — устройство получает общую копию. Без интернета изменения ждут в очереди.
- Команда: владелец создаёт ссылку-приглашение «может менять» или «только смотреть», видит участников,
  меняет роль или убирает. Зритель не может ничего изменить — это проверяет сервер.

## ИИ-помощник

`apps/api` принимает фразу (или фото) и текущее рабочее пространство, даёт Claude инструменты
`add_rows`, `update_cells`, `create_table`, `add_columns`, `delete_rows` и выполняет их через
команды ядра на копии данных. Обратно уходят только операции: приложение показывает их
человеку («так поняла Sumira») и применяет после нажатия «Записать». Отмена — как у любой операции.

## Дизайн

Чёрно-белый, швейцарский: крупный жирный заголовок, толстые линии, большие цифры (Unbounded),
текст Golos Text. Цвет — только у статусов и у акцента, который компания может выбрать сама.
Светлая и тёмная темы. Шрифты лежат локально, чтобы `.exe` работал без интернета.

## Этапы

1. ✅ `core`: модель, разбор ввода, формулы, операции, отмена, итоги, шаблоны + тесты.
2. ✅ `web`: умные таблицы, карточки на телефоне, форма «Записать», 5 языков, локальное хранение.
3. ✅ Дизайн Sumira, приветственный путь («для чего вам Sumira?» → таблицы с объяснением → «опишите словами»).
4. ✅ ИИ-строка: текст, голос, фото → предпросмотр → «Записать».
5. ✅ Связанные таблицы (колонки «Связь» и «Из связи», карточка с записями из других таблиц),
   импорт Excel/CSV с распознаванием типов, выгрузка .xlsx/.csv, сохранённые отчёты с графиками.
6. ✅ «Для вас»: профиль, сроки и праздники, подсказки, лимиты дохода; правила обновляются с сервера.
7. ✅ Доработки после теста на 5 персонах: доход/расход, итоги по связям, цели, кварталы и фильтры,
   сетка как в Excel, доска и календарь, быстрая запись без ИИ, импорт банковских файлов.
8. ✅ Новый первый экран («напишите — и сразу таблица»), телефон как банковское приложение.
   ✅ Аккаунты, облако (SQLite, позже Postgres), синхронизация, команда и права.
   Подписка на ИИ (€10, месяц бесплатно, лимит).
9. Tauri `.exe` + сборка в GitHub Actions.
10. Режим сетки A1 для продвинутых.
