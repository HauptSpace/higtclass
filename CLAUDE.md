# Zifra — гайд для работы над проектом

Этот файл читается в начале каждой сессии. Прочитай его целиком, потом
`docs/architecture.md`. Не начинай с нуля: всё ниже уже решено и проверено.

## Что мы делаем

Zifra — таблицы, которыми может пользоваться любой человек «от бомжа до CEO»:
пишешь «кава 85» или «Олег 12000 оплачено» — запись готова, итоги, налоги и сроки
считаются сами. Сайт + позже Windows `.exe` (Tauri). Языки: ru, uk, en, de, es.
Рынок: Украина, Европа, весь мир. Продукт **вне политики**.

Владелец — украинец, живёт в Германии. Цель — продукт **для всех**, но самая острая
боль, которую Zifra уже закрывает лучше других: ФОП в Украине, самозанятые
украинцы в Германии/Польше/Испании (налоги, лимиты, сроки, отчёт бухгалтеру).

## Как работать с владельцем

- Пишет по-русски, коротко, с опечатками. **Отвечай по-русски**, просто, без
  программистского жаргона. Коротко: что сделано, что проверено, что дальше.
- **«Всегда спрашивай меня»** перед большими шагами и решениями (новая архитектура,
  деньги, внешние сервисы, удаление). Если сказал «делай»/«все короче надо делать» —
  делай без лишних вопросов, но решения называй.
- Говори честно, даже неприятное. Не хвали продукт зря. Если что-то не проверено —
  так и пиши.
- В интерфейсе и текстах **не ругаем Excel** и конкурентов. Говорим, что умеет Zifra.
- **Ключи и пароли никогда не просить вставить в чат.** Ключ Anthropic —
  в `apps/api/.env` (`ANTHROPIC_API_KEY`), файл в git не попадает.
- В коммитах, PR и коде не упоминать названия/версии моделей ИИ.
- Дизайн: ему нравится чёрно-белый швейцарский стиль (крупный жирный шрифт,
  толстые линии). Не любит зелёный как основной цвет, «дешёвый минимализм»,
  детский стиль. Перед сменой стиля — покажи варианты и спроси.

## Бизнес-решения (уже приняты)

- Ядро бесплатно. ИИ-помощник — подписка **€10/мес** везде (и в Украине).
  Первый месяц бесплатно, **без карты**. Пробный период ограничен квотой;
  повторные регистрации ради нового бесплатного месяца надо блокировать
  (проверка почты, одноразовые почты запрещены).
- Модель ИИ по умолчанию — Haiku (`ZIFRA_MODEL`), лимиты чтобы не терять деньги:
  пробный — ~100 запросов / 20 фото; платный — ~1500 запросов / 200 фото в месяц.
- Оплата — Paddle (план). Сервер — Hetzner (план), база сейчас SQLite, позже Postgres.

## Устройство (коротко)

- `packages/core` — чистый TypeScript без зависимостей: типы, разбор ввода на 5 языках
  (`values.ts`, `quick.ts`), формулы (`formula.ts`), операции с отменой (`ops.ts`),
  команды (`commands.ts`), доход/расход и цели (`ledger.ts`), периоды (`periods.ts`),
  итоги/отчёты/фильтры (`aggregate.ts`), шаблоны (`templates.ts`), импорт (`infer.ts`),
  правила «Для вас» — налоги, сроки, праздники (`knowledge.ts`).
- `apps/web` — React 19 + Vite + Tailwind 4 + zustand (IndexedDB). Экраны в
  `src/components`: `Hero` (первый экран), `TableView`, `GridView` (сетка как в Excel),
  `CardsView` (телефон, по дням), `BoardCalendar`, `RecordDialog`, `ColumnDialog`,
  `Reports`, `SummaryView`, `ForYou`, `ImportDialog`, `Account` (вход, команда).
  Синхронизация — `src/cloud.ts`, выгрузка — `src/exporter.ts`, тексты — `src/i18n/*.ts`.
- `apps/api` — Hono: ИИ (`assistant.ts`, `tools.ts`), аккаунты/облако/команда
  (`cloud.ts`, `db.ts` на `node:sqlite`), курсы валют (`rates.ts`), правила (`/api/rules`).

Главный принцип: **любое изменение данных — это операция (`Op`) с обратной**.
Через неё работают отмена, ИИ (предлагает операции, человек жмёт «Записать»)
и синхронизация (устройство шлёт операции, сервер применяет тем же `applyOp`).

## Правила кода

- Код пиши как окружающий: комментарии объясняют **зачем**, простыми словами,
  с примерами («"5.9 кава 60" — дата только если есть другое число»).
- TypeScript строгий, `erasableSyntaxOnly`: без `enum` и parameter properties
  (Node запускает `.ts` напрямую). Строки до ~160 символов. Не прогоняй prettier
  по старым файлам целиком — он переформатирует чужой код.
- **Каждый новый текст — сразу на 5 языках.** Используй
  `python scripts/i18n-add.py keys.py` (формат внутри скрипта). Немецкий — на «Sie».
- Деньги, даты, числа — только через функции ядра (`parseNumber`, `parseDate`,
  `formatValue`, `cellText`): там учтены «1.500», «5к», «вчора», регион браузера.
- Налоговые правила (`knowledge.ts`) меняем **только с источником** (ссылка в правиле).
  Проверенные факты: Kleinunternehmer — 25 000 € за прошлый год / 100 000 € в текущем;
  ФОП 3 группа без НДС — 5% + 1% военный сбор, лимит 2026 — 10 091 049 грн.
- Новые зависимости — только если без них никак.

## Как проверять перед тем, как сказать «готово»

```bash
pnpm test        # ядро (~111 тестов) и API (~10)
pnpm typecheck
pnpm build
```

Плюс глазами: собрать (`pnpm build`), поднять `npx vite preview --port 4173` в
`apps/web` и API (`pnpm dev:api`), пройти сценарий через Playwright на 1440×900 и
**390×844 (телефон)**, сделать скриншоты и посмотреть их. Ошибок в консоли быть
не должно. Сценарии, которые уже гоняли: бюджет Васи (укр., телефон), ФОП Оксаны
(клиенты+оплаты, налоги, Q3), Андрей (Kleinunternehmer, банковский CSV, EÜR),
Марина (склад и продажи, импорт Excel), Сэм (команда клининга, доска, календарь).
Если владелец просит «проверить агентами» — запускай 5 персон-тестеров с этими ролями.

## Что сделано

Ядро, сетка как в Excel, доход/расход/остаток, итоги по связям (остаток на складе),
цели, периоды и фильтры, виды (таблица/карточки/доска/календарь/итоги), отчёты
(клиент × месяц), импорт Excel/CSV (банковские файлы, кодировки), выгрузка с
формулами и итогами, «Для вас» (UA, DE с землями, PL, ES), быстрая запись без ИИ,
фото чеков, курсы НБУ/ЕЦБ, первый экран «напиши — и сразу таблица», телефон как
банковское приложение, аккаунты + облако + команда (ссылки-приглашения, роли).

## Что дальше (по порядку, если владелец не скажет иначе)

1. Подключить ИИ с ключом и **привязать к аккаунту**: квоты, пробный месяц, подписка
   €10 (Paddle), защита от повторных регистраций. Сейчас `/api/assistant` открыт всем.
2. Установка на телефон (PWA: иконка, офлайн, напоминания о сроках).
3. Tauri `.exe` + сборка в GitHub Actions.
4. Сервер на Hetzner, домен, резервные копии базы.
5. Живые люди: страница с обещанием и 5–10 разговоров с ФОП / самозанятыми.

Известные пробелы: интеграция с банками (Монобанк API — сильный аргумент для Украины),
готовые формы для налоговой (книга доходов ФОП, строки EÜR), уведомления команде,
вставка блока в нижнюю строку перезаписывает старую запись (как в Excel).
